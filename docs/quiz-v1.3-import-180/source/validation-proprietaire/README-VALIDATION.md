# Validation du propriétaire — 180 brouillons Intermédiaire et Avancé

Ce ZIP **unique** reprend intégralement le ZIP original des six banques de 30 QCM et ajoute :
- `APPROBATION-PROPRIETAIRE-180.json` : déclaration exacte du propriétaire, 180 identifiants et SHA-256 des banques originales ;
- `PROMPT-CODEX-APRES-VALIDATION.md` : prompt prioritaire pour Codex ;
- `RELEVE-VERIFICATION.md` : dénombrement et limites des contrôles.

La déclaration du propriétaire « j'ai validé les brouillons » porte sur ces **180 questions-réponses**. Elle n'est pas une relecture indépendante et **ne documente pas explicitement** une vérification des citations arabes et des attributions. La V1.3 exige ces deux contrôles supplémentaires avant publication.

Les six JSON sources restent **inchangés octet pour octet**, statut `research-draft` conservé. L'approbation se trouve dans un document distinct, afin de ne pas effacer l'historique ou fabriquer un rapport de revue publiable.
